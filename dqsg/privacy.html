点齐收工隐私政策

适用版本 1.0.0 · 更新于 2026 年 11 月 16 日

点齐收工用于出发清点、收工复核和物品借还记录。本政策说明这些信息如何保存，以及你如何管理它们。

本机存储

应用将你填写的清单名称、场景、物品名称和数量、清点状态、借用人和借出数量，以及外观偏好保存在本机，用于展示和恢复你的清单。借用人可以填写昵称。

1.0.0 可离线使用，无需创建账号。应用不会把清单或借还信息上传给开发者，也没有广告、跨应用跟踪、第三方统计或应用内云同步功能。

修改和删除

你可以从清单右侧的菜单删除单份清单，也可以在「设置 → 删除本机清单」确认删除全部清单和借还记录。若存在系统设备备份，请在 iOS 的备份设置中管理。iOS 的「卸载 App」会保留部分应用数据，请选择「删除 App」以移除该设备上的应用和数据。

访问网页和联系支持

本页面由 GitHub Pages 托管。GitHub 可能为提供和保护网站服务处理 IP 地址、浏览器信息等访问数据，详情见 GitHub 隐私声明。

如果你主动发邮件寻求帮助，我们会使用你提供的邮箱和问题信息来回复。发送截图前请遮挡借用人或其他私人信息。
