挥杆成长隐私政策

适用版本 1.0.0 · 更新于 2026 年 11 月 26 日

挥杆成长用于记录高尔夫训练、逐洞成绩、球场资料和成长节点，并生成个人复盘曲线和报告。

保存在本机的资料

你填写的球场名称、地区、手动选定的球场坐标、发球台、标准杆和长度、评级及其来源、比赛日期、逐洞成绩、训练条件和结果、备注、成长节点及目标保存在本机应用目录。开发者不会接收这些记录。

版本 1.0.0 无需创建账号，使用本机记录和统计时可以离线操作。本版本没有广告、跨应用跟踪、分析 SDK、付费内容或开发者服务器。

地图与搜索

你主动打开球场地图、选取位置或搜索球场时，Apple 地图会处理地图区域、搜索词及提供地图服务所需的网络信息。这些请求由 Apple 处理，具体遵循 Apple 地图与隐私说明。应用使用手动选点，未申请设备定位权限，也未在后台持续获取位置。

文件导出与恢复

你主动导出的 JSON 备份、CSV 和 PDF 报告包含选定的记录。你决定文件的保存位置、共享方式和接收者。请注意备份和报告中的球场、日期及个人备注。导入备份前会校验内容，并由你确认是否替换现有资料。

修改与删除

你可以在球场、比赛、训练和成长节点中编辑或删除资料，也可以在「我的 → 删除全部个人资料」中确认删除全部本机记录。删除球场资料后，历史比赛会保留其比赛当时的球场快照；如需一并移除，请删除对应比赛或全部资料。你导出的文件需要在对应文件存储位置自行删除。

iOS 可能按照你的系统设置备份应用数据。请在设备设置中管理 iCloud 或电脑备份。删除应用与卸载应用的数据保留方式由 iOS 决定。

网站与邮件支持

本网页由 GitHub Pages 托管。GitHub 可能处理访问网站所需的 IP 地址、浏览器信息等数据，详情见 GitHub 隐私声明。你主动发送支持邮件时，开发者会使用你提供的邮箱和问题内容进行回复。请在发送截图前遮挡私人信息。
