隐私政策技术支持

芳疗志 · 隐私政策

更新日期：2026 年 10 月 15 日｜适用版本：1.1 及后续启用相同广告功能的版本｜应用标识：com.zhixun.lfz

本页适用于带广告与联网服务的芳疗志版本。1.0 版本请查看对应隐私政策。开发者通过 GitHub 账号 MorningStar-Lu 提供支持。

1. 配方仍由你在本机保管

配方名称、香材比例、香气家族、闻香笔记、收藏状态和建档时间用于本机档案管理，不作为设备注册或广告事件请求的内容上传。复制、导出仅在你操作时将 JSON 写入系统剪贴板，由你选择后续分享位置。应用暂不支持 JSON 导入恢复或应用内云同步。

2. 后端连接与广告事件

在你同意本说明后，应用连接 qzzhixun.cn，发送本应用安装 UUID 与 Bundle ID 进行设备注册，获取后端账号、应用状态及广告配置。服务器也会在网络通信中接收到 IP 地址。安装 UUID 存放于本机钥匙串，不使用 iCloud 同步；删除应用后，该钥匙串标识仍可能保留，重新安装时可能继续使用。清理配方不清理这个安装标识。

广告展示或 SDK 确认奖励后，应用会直接上报后端账号、广告类型、广告位及广告素材来源标识、收益金额、事件时间、渠道名称；激励成功另带确认标记，横幅事件另带刷新类型。这些信息用于广告统计、配置轮转和反作弊。网络失败的事件不建立本机持久重传队列；本机激励完成记录与上报独立保留。

3. 广告 SDK 与第三方接收方

广告由 Taku 聚合服务及下列集成的广告 SDK 提供。启用相应广告源时，SDK 通过其接口直接处理设备和系统信息、网络及 IP 信息、设备标识、广告展示/点击/转化、崩溃和性能信息，用于投放、效果分析、反作弊及稳定性维护。部分广告交互可能使用设备传感器。具体字段、可选采集和第三方处理规则请查阅各提供方政策。本应用不主动申请定位、相机或相册权限。

4. 同意、保存与删除

首次使用广告版本时会先展示隐私说明，同意前不初始化广告 SDK、不设备注册。拒绝系统追踪授权不限制本机配方功能。应用不提供单独关闭联网广告服务的开关。

配方可在详情页逐条删除。本机操作记录保留最近至多 200 条已确认激励时间及上次完成时间，不提供单独清空按钮。删除 App 可移除沙盒业务数据，但不保证删除钥匙串标识、服务器已有记录、你导出的文件或系统备份。“卸载 App”保留数据功能与“删除 App”不同。

如需查询、更正、删除后端相关信息或撤回同意，请通过下方开发者支持渠道提出请求，可提供操作记录页中的账号帮助定位，切勿公开提交完整配方或敏感个人信息。第三方已处理的数据也可通过其隐私政策所列渠道提出请求。服务器及第三方数据的删除范围和时间取决于相应处理规则及适用要求；本应用没有承诺卸载即删除所有远端记录。

5. 外部页面与安全

打开政策和支持页会通过浏览器访问 GitHub Pages，浏览器和 GitHub 会按其规则处理访问数据。本页面无统计脚本和表单。业务数据由应用沙盒保护，安装身份由系统钥匙串保护，后端接口使用 HTTPS；请妥善保管设备与导出的备份。香材说明仅用于香气记录，不构成医疗建议或使用剂量。

6. 联系与更新

技术支持提供开发者联系入口。公开 Issue 可能被他人查看，隐私请求请避免公开敏感内容。处理方式变化时会更新政策，并在需要时重新征得同意。
