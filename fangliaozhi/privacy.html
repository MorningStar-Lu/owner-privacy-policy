隐私政策技术支持

芳疗志 · 隐私政策

生效日期：2026 年 10 月 11 日｜适用版本：1.0｜应用标识：com.zhixun.lfz

本政策说明芳疗志当前版本如何处理信息。开发者通过 GitHub 账号 MorningStar-Lu 提供本页面和支持渠道。

1. 本机处理的信息

你录入的配方名称、香材名称、相对份数、香气家族、闻香笔记、收藏状态和建档时间存放在应用的本机存储中，用于管理、搜索和展示配方。

应用保留“操作记录”入口，用于展示经广告 SDK 确认的激励完成时间与次数。当前版本没有启用广告 SDK、广告展示、设备注册或广告事件上报，因此不会因保存配方生成激励记录，也不会在这一入口生成后端账号。

2. 当前版本的数据收集与传输

当前应用不要求注册登录，不将配方、笔记或本机操作记录主动上传至开发者服务器；未启用广告追踪、广告标识符读取、第三方分析或应用内云同步。不请求相机、相册、位置或跟踪权限。

当你打开隐私政策或支持链接时，系统浏览器会连接 GitHub Pages。GitHub 可能为网站运行和安全处理 IP 地址、浏览器信息等访问数据，具体见 GitHub 隐私声明。本页面没有添加统计脚本、广告或表单。

3. 导出与剪贴板

仅当你主动点击复制或导出时，应用将所选配方或全部配方的 JSON 文本写入系统剪贴板。之后粘贴、分享或备份到哪里由你决定；请留意共享设备和剪贴板中可能包含的个人笔记。

4. 保存与删除

配方可以在详情中逐条删除。本机操作记录不提供单独清空入口。删除应用可移除应用在本机的存储；iOS 的“卸载 App”保留数据选项与“删除 App”不同。你自行导出的副本、系统设备备份中的数据需在对应位置管理。芳疗志当前未提供应用内 iCloud 备份或同步。

5. 安全与使用范围

本机数据由系统应用沙盒和设备访问控制保护，请为设备设置密码并妥善保管导出文件。电子存储无法保证绝对安全。香材说明与比例记录仅用于整理香气档案，不构成医疗建议、疗效承诺或皮肤使用剂量。

6. 联系与政策更新

如需帮助或有隐私问题，请访问技术支持页面。公开 GitHub Issue 可能被他人查看，请勿提交敏感配方、个人信息或完整数据文件。

未来版本若启用广告、设备标识或后端服务，将在启用前更新本政策和商店隐私申报，并根据实际行为提供相应的权限说明。本政策不将尚未启用的广告功能视为当前版本已经采集的数据。
