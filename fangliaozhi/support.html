应用：芳疗志｜版本：1.0

芳疗志用于记录精油与香氛配方的相对比例、香气家族和闻香笔记。所有配方由你在本机管理。

联系我们

通过 GitHub 提交问题反馈，或查看已有问题。提交 Issue 需要 GitHub 账号。建议提供应用版本、iOS 版本、设备型号、操作步骤与经过遮挡的错误截图。请注明“芳疗志”。

该渠道为公开渠道，请勿发送密码、身份信息、私人笔记或完整配方导出文件。请先对截图中的私人内容做遮挡。我们会通过对应 Issue 回复，不承诺固定回复时间。

如何保存和编辑配方？

在“配方档案”点击“新建配方”，填写名称、香材和正数份数后保存。点击已有档案进入详情，可以编辑、收藏、复制或删除。份数用于比较比例，不代表使用剂量。

如何备份？

在“数据掌控”点击“导出全部配方”，将 JSON 文本复制后粘贴到你保管的文件或笔记中。当前版本尚不支持将 JSON 文件导入恢复，导出不会自动上传至云端。

操作记录为什么为空？

操作记录只统计经广告 SDK 确认的激励完成。当前版本未启用广告，显示“暂无操作记录”和“当前未连接后端账号”是正常情况。保存配方不会增加激励次数。

显示“无法读取”时怎么办？

可尝试点击“重新读取”并重新启动应用。不要先删除应用，避免丢失本机数据。若仍失败，请通过上述渠道提供错误信息和操作步骤。
