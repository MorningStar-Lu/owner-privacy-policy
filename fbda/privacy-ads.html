隐私政策技术支持使用帮助

飞镖档案 · 隐私政策

更新日期：2026 年 10 月 24 日｜适用版本：1.1 及后续广告服务版本（包括 1.2.1）

欢迎使用飞镖档案。我们尊重您的隐私，本政策说明您使用应用时涉及的信息处理方式，以及管理相关信息的途径。请在使用前阅读；广告及相关服务会在您同意本政策后启用。

一、我们处理的信息

飞镖档案不要求您注册个人账户，也不要求填写姓名、手机号或身份证件。您录入的训练日期、投镖数量、得分、目标命中情况、训练备注，以及镖具名称、重量、配件和手感备注等内容保存在设备本地，用于记分、管理档案和展示成长曲线，不会作为广告投放或统计的内容上传。未存档的对局过程仅在当前运行期间保留。

为提供广告展示、服务配置及运行保障，应用会向开发者服务（qzzhixun.cn）发送随机安装标识和应用标识，自动获得服务账号，并获取广告配置与服务状态。广告确认展示或奖励确认时，还会发送服务账号、广告类型、广告位及广告来源、收益、时间和渠道等相关记录；激励广告仅在平台确认奖励后发送完成事件。这些记录不包含您的训练和镖具明细。

广告合作方还可能处理设备与系统信息、网络环境及 IP 地址、设备标识、广告展示、点击与转化、运行诊断及性能信息，用于广告投放、效果统计、安全防护和服务维护。部分广告交互可能涉及加速度、陀螺仪等传感器信息，具体以实际启用的平台及其说明为准。

广告标识符 IDFA 的使用以系统追踪授权为前提。您可在 iOS“设置 → 隐私与安全性 → 跟踪”中管理授权，重新启动应用后按新的状态生效。拒绝追踪不影响本机记分、训练与镖具管理功能；应用按非个性化方式配置广告，其他必要的设备、网络及广告服务信息仍可能按本政策处理。应用不主动申请定位、相机、麦克风或相册权限。

二、信息的存储与安全

训练、镖具及经广告平台确认的激励完成记录保存在设备本地。激励记录包含奖励请求标识和完成时间，与训练及镖具备份分开保存。随机安装标识保存在本应用的系统钥匙串中，不同步至 iCloud；清除业务数据不会删除它，删除并重新安装应用后该标识也可能继续使用。

您主动点击“备份个人档案”时，应用将训练和镖具的 JSON 文本写入系统剪贴板，保存与分享位置由您决定。恢复只处理您主动粘贴的备份，经验证和确认后替换当前业务档案；不会自动读取剪贴板，也不包含激励记录。当前未提供应用内 iCloud 备份或云同步。

我们采取合理措施保护信息，仅在提供服务所需的范围内保存和使用。广告相关信息由相应服务方依其隐私政策处理。请为设备设置密码并妥善保管备份；任何电子存储或网络传输方式都无法保证绝对安全。

训练和镖具可在应用内逐条删除，也可通过“我的档案 → 清除业务数据”清除。删除镖具会解除关联，但保留训练。清除业务数据不会清除激励记录；激励记录没有单独清空入口。删除 App 可移除相应沙盒数据，但不会同时删除钥匙串标识、自行导出的副本、系统备份或服务方保存的信息。如需查询、更正、删除相关服务信息或撤回同意，请通过下方邮箱联系；我们会核实请求并说明处理结果，第三方信息也可向相应服务方提出请求。

三、信息的共享与披露

我们不会出售您的训练、镖具资料和私人笔记。为提供广告及相关服务，必要的设备、网络与广告事件信息会由广告合作方处理；此外，仅在您同意、主动分享，或法律法规及有权机关要求的情况下提供相应信息。

当您打开隐私、帮助或支持网页时，浏览器会连接 GitHub Pages，GitHub 可能处理网站运行与安全所需的访问数据，具体见GitHub 隐私声明。这些网页没有添加统计脚本、广告或收集表单。通过 GitHub Issue 反馈时，您提交的内容可能公开展示。

四、第三方广告服务

本应用接入 Taku 聚合广告 SDK（服务方：广州塔酷信息科技有限公司），并集成快手、优量汇、百度、倍孜、Taku Adx 和美数适配器。实际参与广告请求的平台取决于广告源配置与填充结果。相关服务可能使用设备标识等信息，提供广告展示、个性化推荐、效果统计及反作弊；IDFA 仅在获得系统追踪授权后获取和使用。

相关处理规则、数据类型和合作方说明请查阅Taku 隐私政策及iOS 数据收集说明。本应用不会向广告服务提交训练笔记、镖具备注或备份文件。

应用可能展示开屏、横幅、原生、插屏或激励广告。新增训练先保存本机数据，再尝试激励广告；只有平台确认奖励后才增加激励完成次数。没有广告填充、播放失败或未获得奖励，不会撤销已经保存的训练。编辑训练不进入新增广告链。

五、未成年人保护

未成年人请在监护人指导下阅读本政策并使用应用。若监护人发现未成年人的相关信息需要处理，可通过下方联系方式提出请求，我们会在核实后提供协助。

六、政策的更新

我们可能随功能或服务调整更新本政策，并更新页面日期。涉及信息处理目的、方式或范围的重要变化时，会通过适当方式提示您，并在需要时重新征得同意。本页适用于启用广告服务的 1.1 及后续版本（包括 1.2.1）；未启用广告服务的原 1.0 版本说明见对应隐私政策。

七、联系我们

如对隐私政策或信息处理有疑问、意见或请求，请联系 yvinus@qq.com，或访问技术支持页面。申请处理服务信息时，可通过邮箱提供应用名及“激励记录”页显示的服务账号，以便核实；请勿在公开反馈中提交敏感个人信息、私人笔记或完整备份文件。
