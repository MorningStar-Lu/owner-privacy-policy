飞镖档案 · 广告版隐私政策

更新日期：2026 年 10 月 21 日｜适用：接入广告服务的版本｜应用标识：com.zhixun.fbda

本政策适用于飞镖档案新增广告服务的版本。此前不含广告的版本仍适用原版隐私政策。广告 SDK 仅在你同意本政策后初始化。

1. 本地训练与镖具档案

训练日期、投镖数量、得分、命中次数、训练备注和镖具资料保存在本机，用于记分、统计与成长曲线，不作为广告事件发送。备份只在你主动操作时复制 JSON，恢复只处理你粘贴的内容。演示数据不计入个人训练档案。

2. 开发者广告服务

应用通过 HTTPS 连接 qzzhixun.cn，使用本应用独立的随机安装标识和应用包名注册设备并获得服务账号，获取广告位、间隔和服务状态。安装标识保存在本应用钥匙串中，不与 iCloud 同步，清除训练数据不会删除该标识；删除应用后钥匙串中的标识可能仍保留。

广告确认展示后，应用向该服务发送服务账号、广告类型、广告位和广告源标识、收益值、展示时间、渠道信息及横幅刷新标记。激励广告只在 SDK 确认奖励时发送完成事件。事件直接发送，失败不建立持久化重试队列。服务提供方为连接和安全处理网络请求时也会接触 IP 等必要网络信息。

3. Taku 与第三方广告 SDK

应用集成 Taku 聚合 SDK，以及快手、优量汇、百度、倍孜、Taku Adx 和美数适配器。实际参与广告请求的平台取决于后台广告源配置和填充结果。SDK 通过自身代码采集广告投放、效果统计、运行诊断和反作弊所需的信息；具体字段随平台与授权状态而不同。

  • 设备与网络：系统和应用版本、设备型号、屏幕信息、语言、时区、网络类型、IP 地址等。
  • 标识信息：安装标识、IDFV；IDFA 仅在系统允许跟踪后按 SDK 行为使用。
  • 广告与诊断：展示、点击、转化等广告交互，以及崩溃和性能数据。

各平台的具体处理规则、运营主体及第三方列表请查阅 Taku 隐私政策、iOS 数据收集说明和第三方 SDK 信息清单。这些服务不会因为本应用集成而获得你的训练笔记、镖具备注或备份文件。

4. 跟踪授权与广告展示

应用通过系统 ATT 提示请求跟踪许可。你可拒绝，并可在 iOS 设置中更改授权。拒绝不会限制本地记分、训练和镖具功能；应用将按非个性化方式配置 SDK，并限制 IDFA 上传。拒绝跟踪不等于停止所有广告请求。

训练页可展示横幅及原生广告。新增训练入口和保存回执退出时可能展示插屏；训练在本机保存成功后可能尝试激励广告。广告失败、提前关闭或没有填充不会撤销已经保存的训练。编辑记录不进入新增广告链。

5. 激励记录与删除

只有 SDK 确认奖励后，才在本机保存请求标识与秒级完成时间并增加次数，同一次展示只确认一次。激励记录与训练备份分开保存。清除训练与镖具不会清除激励记录，也不会删除安装标识。若本机存储读取失败，应用显示读取失败和重试入口。

训练与镖具可在应用内逐条删除或清除。删除 App 可移除沙盒数据，但不保证删除钥匙串标识或你自行导出的副本。涉及开发者广告服务中的账号或事件删除请求，请通过技术支持联系并提供应用内服务账号，勿公开发送私人笔记。

6. 权限、外部链接与联系

本应用不为广告请求相机、麦克风、相册或精确位置权限。打开帮助及隐私网页时，浏览器会连接 GitHub Pages，网站访问适用 GitHub 的隐私规则。支持渠道为公开 GitHub Issue，请先遮挡个人信息。

请通过技术支持反馈隐私问题。我们会根据实际功能和第三方处理情况更新政策；涉及重大变化时会在启用前提供新的说明。
