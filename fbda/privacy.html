飞镖档案 · 隐私政策

更新生效日期：2026 年 10 月 18 日 · 适用版本：1.0
应用标识：com.zhixun.fbda · 开发者支持账号：MorningStar-Lu

本政策说明飞镖档案当前版本的信息处理方式，覆盖训练日志、单人记分、镖具档案、备份恢复及帮助链接。

1. 设备内处理的信息

应用在本机保存你录入的训练类型、日期、投镖数量、累计得分、目标尝试与命中次数、训练备注，以及镖具名称、重量、镖筒、镖翼和手感备注。记录标识及镖具关联用于组织档案和绘制成长曲线。

当前对局的逐镖记分在运行期间保存在内存中；只有你主动存档时，对局汇总才保存为训练记录。当前版本不支持未存档对局的自动恢复。

应用另有独立的激励记录存储，用于记录已确认奖励的请求标识与完成时间。当前未接入广告 SDK 或后端，不会因训练保存生成激励记录；演示数据也不生成激励记录。

2. 信息用途与保存方式

上述信息用于记分、均分与命中率计算、训练和镖具管理、成长图表、备份与恢复。档案以 JSON 形式保存在应用本机存储中。演示数据用于展示功能，不写入个人档案。

3. 当前应用不主动上传档案

当前版本不要求注册登录，不将训练、镖具或备注主动上传至开发者服务器，未启用广告 SDK、广告标识符读取、第三方统计或应用内云同步。不请求相机、麦克风、相册、位置或跟踪权限。

4. 剪贴板备份与恢复

只有你点击“备份个人档案”时，应用才把档案 JSON 写入系统剪贴板。保存到哪里、是否分享由你决定。恢复时，应用处理你主动粘贴到输入框的 JSON，不会自动读取剪贴板；验证并确认后替换现有档案。备份可能包含私人备注，请妥善保管。

5. GitHub Pages 与支持渠道

你主动打开帮助、隐私政策、技术支持或反馈入口时，系统浏览器连接 GitHub Pages 或 GitHub。GitHub 可能处理 IP 地址、浏览器及设备信息、访问记录和你提交的内容，详见 GitHub 隐私声明。本网站没有加入统计脚本、广告或数据上传表单。

GitHub Issue 属于公开渠道。反馈内容由你主动提交，可能被其他人查看；请勿发布个人信息、完整档案或未遮挡的私人截图。应用不会自动附加训练数据或代你提交反馈。

6. 保留、删除与副本

你可以在应用内删除训练记录和镖具。删除镖具会解除训练中的关联，保留训练本身。你也可以在“我的档案”选择“清除业务数据”，确认后删除全部训练和镖具；该操作不包含独立保存的激励记录。系统删除应用可能移除对应本机数据；保留 App 数据的卸载选项与删除应用不同。设备系统备份及自行导出的副本需要在对应位置管理，当前应用未提供 iCloud 同步。

7. 数据保护与曲线说明

本机档案依赖系统应用沙盒和设备访问控制保护，并非应用级加密数据库。请妥善保管设备和备份副本。曲线仅用于整理和比较记录，不承诺训练效果；镖具节点不构成进步原因的证明。

8. 联系与更新

如有信息处理问题，请通过技术支持页面联系开发者。后续若增加广告、云同步、账户或其他信息处理功能，将在对应功能启用前更新本政策和相关说明。
