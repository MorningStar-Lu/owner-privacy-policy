使用帮助隐私政策技术支持

飞镖档案 · 隐私政策

生效日期：2026 年 10 月 18 日｜适用版本：1.0｜应用标识：com.zhixun.fbda

本政策说明飞镖档案当前版本如何处理信息。开发者通过 GitHub 账号 MorningStar-Lu 提供本页面和支持渠道。

1. 本机处理的信息

你录入的训练类型、训练日期、投镖数量、累计得分、目标尝试与命中次数、训练备注，以及镖具名称、重量、镖筒、镖翼和手感备注，存放在应用的本机存储中，用于管理档案、记分统计和展示成长曲线。未存档对局的逐镖过程仅在当前运行期间保留。

应用提供“激励记录”入口，用于展示经广告 SDK 确认的激励完成时间与次数，独立记录中包含奖励请求标识与完成时间。当前版本没有启用广告 SDK、广告展示、设备注册或广告事件上报，因此不会因保存训练生成激励记录，也不会在这一入口生成后端账号。

2. 当前版本的数据收集与传输

当前应用不要求注册登录，不将训练、镖具、笔记或本机激励记录主动上传至开发者服务器；未启用广告追踪、广告标识符读取、第三方分析或应用内云同步。不请求相机、麦克风、相册、位置或跟踪权限。

当你打开隐私政策或支持链接时，系统浏览器会连接 GitHub Pages。GitHub 可能为网站运行和安全处理 IP 地址、浏览器信息等访问数据，具体见 GitHub 隐私声明。本页面没有添加统计脚本、广告或表单。

3. 备份、恢复与剪贴板

仅当你主动点击“备份个人档案”时，应用将训练和镖具档案的 JSON 文本写入系统剪贴板。之后粘贴、分享或备份到哪里由你决定；请留意共享设备和剪贴板中可能包含的个人笔记。

恢复备份时，应用只处理你主动粘贴到输入框中的内容，不会自动读取剪贴板。备份经验证并由你确认后，替换当前训练和镖具档案。业务备份与恢复不包含激励记录。

4. 保存与删除

训练和镖具可以逐条删除，也可以在“我的档案”中选择“清除业务数据”，确认后清除全部训练和镖具。删除镖具会解除相关训练的镖具关联，保留训练本身。清除业务数据不会删除激励记录，激励记录不提供单独清空入口。

删除应用可移除应用在本机的存储；iOS 的“卸载 App”保留数据选项与“删除 App”不同。你自行导出的副本、系统设备备份中的数据需在对应位置管理。飞镖档案当前未提供应用内 iCloud 备份或同步。

5. 安全与使用范围

本机数据由系统应用沙盒和设备访问控制保护，请为设备设置密码并妥善保管导出文件。电子存储无法保证绝对安全。记分、训练统计与成长曲线用于整理个人记录，不承诺训练效果；镖具与成绩的时间关联不代表因果关系。

6. 联系与政策更新

如需帮助或有隐私问题，请访问技术支持页面。公开 GitHub Issue 可能被他人查看，请勿提交私人训练笔记、个人信息或完整数据文件。

未来版本若启用广告、设备标识或后端服务，将在启用前更新本政策和商店隐私申报，并根据实际行为提供相应的权限说明。本政策不将尚未启用的广告功能视为当前版本已经采集的数据。
