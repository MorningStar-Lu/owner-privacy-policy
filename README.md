# 持物本 隐私政策

生效日期：2026 年 7 月 14 日

持物本（以下简称“本应用”）重视并保护用户隐私。本隐私政策说明本应用在你使用过程中如何处理信息，以及你可以如何管理相关数据。

## 1. 我们收集的信息

本应用主要用于记录和管理个人资产、折旧、附加成本和相关操作流水。根据你使用的功能，本应用可能在本地处理以下信息：

- 你主动录入的资产信息，例如物品名称、分类、购买日期、购买价格、预计寿命、残值、备注、卖出价格等。
- 你主动录入或由本应用生成的附加成本、资产状态、折旧计算结果和统计数据。
- 免广告权益相关信息，例如兑换状态、剩余免广告天数、奖励或扣减流水。
- iCloud 备份相关数据，例如本地 SQLite 数据库备份文件、免广告状态快照和备份时间。

上述资产、账单、备注及统计数据均存储在你的设备本地或你自己的 iCloud 容器中，不会提供给广告合作伙伴。

为展示第三方广告，本应用及第三方广告合作伙伴可能收集设备 ID，包括系统提供的广告标识符或本应用生成并保存在系统安全存储中的设备级标识符。设备 ID 不包含你在本应用中录入的资产、账单或备注内容。

## 2. 信息的存储方式

本应用优先将数据存储在你的设备本地，包括本地数据库、SharedPreferences、系统安全存储或应用沙盒文件中。

如果你使用 iCloud 备份或恢复功能，本应用会将相关备份文件上传至你自己的 iCloud 容器中，用于在你的设备之间恢复数据。iCloud 数据由 Apple 提供的 iCloud 服务管理，本应用不会将该部分数据公开发布。

## 3. 信息的使用目的

本应用处理信息仅用于以下目的：

- 展示、管理和计算你的资产日耗、残值、统计数据和资产状态。
- 提供本地备份、iCloud 备份与恢复能力。
- 记录免广告权益、兑换码状态、奖励天数和扣减流水。
- 改善应用功能稳定性、数据一致性和用户体验。
- 使用设备 ID 展示第三方广告，以及进行与第三方广告展示相关的归因、频次控制和广告效果衡量。

本应用不会将设备 ID 用于开发者广告或营销、用户行为分析、产品个性化或其他未声明用途。

## 4. 第三方服务

本应用使用以下系统服务和第三方服务：

- Apple iCloud：用于你主动触发的数据备份与恢复。
- Apple 系统能力：例如应用沙盒、Keychain、广告标识符和 App Tracking Transparency（ATT）权限。
- 第三方广告服务：用于加载和展示横幅、原生、插屏、开屏或激励广告。广告合作伙伴可能按照其隐私政策处理设备 ID、广告展示及广告交互相关信息。

本应用集成第三方广告 SDK。第三方广告合作伙伴的数据处理规则由其各自的隐私政策约束。

## 5. 数据共享

本应用不会出售或出租你录入的资产、账单、备注或其他个人内容，也不会将这些内容提供给广告合作伙伴。

为了展示第三方广告，设备 ID 可能会传输给第三方广告合作伙伴，并可能用于广告归因或广告效果衡量。你主动使用 iCloud 备份或恢复功能时，备份数据会通过 Apple iCloud 服务处理，由 Apple 的隐私政策管辖。

## 6. 权限说明

本应用可能根据功能需要请求 iCloud 访问和 App Tracking Transparency（ATT）等系统权限。你可以在系统设置中管理相关权限。拒绝跟踪权限不会阻止你使用本应用的主要功能，但第三方广告可能不再具有针对性；关闭 iCloud 权限可能影响备份与恢复功能。

## 7. 数据保留与删除

本应用的本地数据通常会保留在你的设备中，直到你主动删除应用、清除数据或在应用内执行相关删除操作。

本应用生成的设备 ID 会保存在系统 Keychain 中。根据 Apple 系统机制，卸载应用后该标识符可能仍会保留。你可以通过“联系我们”所述方式申请处理与设备 ID 相关的数据；第三方广告合作伙伴的数据保留期限以其隐私政策为准。

iCloud 备份数据保留在你的 iCloud 账户中。你可以通过系统 iCloud 设置、应用内恢复/覆盖功能或删除应用数据的方式管理相关备份。

## 8. 数据安全

本应用会采取合理措施保护数据安全，例如使用系统沙盒、本地存储、iCloud 容器和必要的接口访问控制。但请理解，任何电子存储或网络传输方式都无法保证绝对安全。

## 9. 儿童隐私

本应用不面向未满 13 周岁的儿童，也不会有意收集儿童个人信息。如果你认为儿童向本应用提供了个人信息，请与我们联系，我们会在核实后采取合理措施处理。

## 10. 政策更新

我们可能会根据功能变化、法律法规要求或服务调整更新本隐私政策。更新后的隐私政策会通过本页面或应用内适当位置展示。继续使用本应用即表示你理解并接受更新后的政策。

如果你对本隐私政策或数据处理方式有任何问题，可以通过 GitHub 仓库 Issue 与我们联系。
