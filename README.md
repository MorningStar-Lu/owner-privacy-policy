# Owner 隐私政策

生效日期：2026 年 6 月 11 日

Owner（以下简称“本应用”）重视并保护用户隐私。本隐私政策说明本应用在你使用过程中如何处理信息，以及你可以如何管理相关数据。

## 1. 我们收集的信息

本应用主要用于记录和管理个人资产、折旧、附加成本、免广告权益和相关操作流水。根据你使用的功能，本应用可能处理以下信息：

- 你主动录入的资产信息，例如物品名称、分类、购买日期、购买价格、预计寿命、残值、备注、卖出价格等。
- 你主动录入或由本应用生成的附加成本、资产状态、折旧计算结果和统计数据。
- 免广告权益相关信息，例如兑换状态、剩余免广告天数、奖励或扣减流水。
- 广告相关事件信息，例如广告位标识、广告类型、展示时间、估算收益等，用于广告展示、去重和上报。
- 设备相关标识，例如本应用生成或读取的本地设备标识，用于登录、广告上报、数据同步或防重复处理。
- iCloud 备份相关数据，例如本地 SQLite 数据库备份文件、免广告状态快照和备份时间。

## 2. 信息的存储方式

本应用优先将数据存储在你的设备本地，包括本地数据库、SharedPreferences、系统安全存储或应用沙盒文件中。

如果你使用 iCloud 备份或恢复功能，本应用会将相关备份文件上传至你自己的 iCloud 容器中，用于在你的设备之间恢复数据。iCloud 数据由 Apple 提供的 iCloud 服务管理，本应用不会将该部分数据公开发布。

## 3. 信息的使用目的

本应用处理信息仅用于以下目的：

- 展示、管理和计算你的资产日耗、残值、统计数据和资产状态。
- 提供本地备份、iCloud 备份与恢复能力。
- 记录免广告权益、兑换码状态、奖励天数和扣减流水。
- 展示广告、控制广告冷却、记录广告曝光并在网络可用时上报。
- 改善应用功能稳定性、数据一致性和用户体验。

## 4. 第三方服务

本应用可能使用以下第三方或系统服务：

- Apple iCloud：用于你主动触发的数据备份与恢复。
- Apple 系统能力：例如应用沙盒、设备权限、广告跟踪授权提示等。
- 广告服务或广告 SDK：用于展示广告、统计广告曝光和处理广告相关事件。
- 后端接口服务：用于渠道配置、登录凭证、广告上报和激励答题上报等功能。

第三方服务可能依据其自身隐私政策处理相关数据。你可以在系统设置或第三方服务的官方渠道中进一步了解其隐私实践。

## 5. 数据共享

除实现本应用功能所必需的场景外，本应用不会出售、出租或以其他方式向无关第三方披露你的个人数据。

在以下情况下，相关数据可能被传输或处理：

- 你主动使用 iCloud 备份或恢复功能时，备份数据会通过 Apple iCloud 服务处理。
- 本应用进行广告展示、广告曝光记录或广告上报时，可能向广告服务或后端接口发送必要的广告事件数据。
- 为满足法律法规、监管要求、司法程序或保护用户及应用安全所必需的情况。

## 6. 权限说明

本应用可能根据功能需要请求系统权限。具体权限取决于你使用的功能和系统版本，包括但不限于网络访问、iCloud 访问、广告跟踪授权提示等。

你可以在系统设置中管理相关权限。关闭某些权限可能会影响对应功能，例如 iCloud 备份、广告个性化或数据同步。

## 7. 数据保留与删除

本应用的本地数据通常会保留在你的设备中，直到你主动删除应用、清除数据或在应用内执行相关删除操作。

iCloud 备份数据保留在你的 iCloud 账户中。你可以通过系统 iCloud 设置、应用内恢复/覆盖功能或删除应用数据的方式管理相关备份。

## 8. 数据安全

本应用会采取合理措施保护数据安全，例如使用系统沙盒、本地存储、iCloud 容器和必要的接口访问控制。但请理解，任何电子存储或网络传输方式都无法保证绝对安全。

## 9. 儿童隐私

本应用不面向未满 13 周岁的儿童，也不会有意收集儿童个人信息。如果你认为儿童向本应用提供了个人信息，请与我们联系，我们会在核实后采取合理措施处理。

## 10. 政策更新

我们可能会根据功能变化、法律法规要求或服务调整更新本隐私政策。更新后的隐私政策会通过本页面或应用内适当位置展示。继续使用本应用即表示你理解并接受更新后的政策。

## 11. 联系我们

如果你对本隐私政策或数据处理方式有任何问题，可以通过 GitHub 仓库 Issue 与我们联系。
